# ODIN RECIPE PROJECT

## DESCRIPTION
This is my First Project of The Odin Project Foundation course. The Project is "Recipe" made using HTML. This Project Helps me to solidify my understanding of the HTML topics that I learnt from The HTML Foundations. This Project taught me, "How to structure files", "How to link multiple HTML pages", "How to create Lists in HTML", "Using the right tags for content" and many more.

### The List of topics I learned from this project

- Heading tags
- Links
- Images
- Folder structure
- Lists
- semantic tags
- and most importantly Problem-solving

### Folder Structure

```text
odin-recipes/
├──images/
├──recipes/
|  ├──chicken_biryani.html
```
